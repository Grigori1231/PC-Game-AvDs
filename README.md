AvDs-Roguelike-Game
Язык программирования: C#
Среда разработки: Visual Studio 2022
Формат данных: JSON (для сохранения прогресса и рекордов)
Архитектура: Объектно-ориентированное программирование (ООП)
AvDs это компьютерная игра в жанре roguelike, расшифровывается как Angel vs Demons
в игре есть: Меню, список врагов, краткий сюжет и игровой процесс с повышением уровня персонажа, выбором способностей и улучшением характеристик, игру можно поставить на паузу, во время паузы игрок может увидеть характеристики персонажа или выйти в меню, в меню можно увидеть количество побеждённых врагов, его можно сбросить с помощью кнопки сбросить рекорд
