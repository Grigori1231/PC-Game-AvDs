AvDs-Roguelike-Game
Язык программирования: C#
Среда разработки: Visual Studio 2022
Формат данных: JSON
Архитектура: Объектно-ориентированное программирование
AvDs это компьютерная игра в жанре roguelike, расшифровывается как Angel vs Demons
в игре есть: Меню, список врагов, краткий сюжет и игровой процесс с логикой повышения уровня персонажа, выбором способностей и улучшением характеристик, игру можно поставить на паузу с помощью esc, во время паузы игрок может увидеть характеристики персонажа или выйти в меню, в меню можно увидеть количество побеждённых врагов, счёт можно сбросить с помощью кнопки сбросить рекорд. В видах врагов есть список различных демонов с разными характеристиками. Ещё есть окно с кратким сюжетом игры который можно прочесть.

- `Program.cs` — точка входа
- `MainMenuForm.cs` — главное меню и рекорды
- `StoryForm.cs` — окно сюжета
- `EnemyTypesForm.cs` — список врагов
- `GameForm*.cs` — игровая логика
- `AbilityPicker.cs` / `BuffCatalog.cs` — способности и баффы
- `Save.cs` — сохранение/загрузка данных в JSON

- Открыть `Rogalik.csproj` или solution в Visual Studio 2022
- Нажать Run (F5)
